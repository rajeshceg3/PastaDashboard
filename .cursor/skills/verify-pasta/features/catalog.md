# Catalog, filters and search
## Sub-features
Ten pasta entries, type filtering, ascending/descending sort, case-insensitive name/description search, empty results and original schematic shape studies. Each card is a native Streamlit bordered container, not orphan HTML around unrelated widgets.
## User route
Open dashboard, use sidebar Select Pasta Type and Sort Pasta By. Mobile sidebar is initially collapsed; open the real sidebar control for filters, close it to reach search. Enter search and press Enter.

## Limits
Source JSON's historical origin and name-meaning claims remain inherited, not independently certified. Sorted display retains actual row/mobile order. No accounts, favorites, recipes or comparison journey is implemented by this repair. Fulldesign/accessibility/live acceptance remains separate.
